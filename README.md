### 🚀 Sobre mim

Desenvolvedor que gosta de construir produtos que funcionam de verdade — do frontend ao backend, passando por pagamentos, autenticação e deploy.

Trabalho principalmente com:

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite
- **Backend**: Node.js, Express, tRPC, Netlify Functions
- **Banco de dados**: Drizzle ORM, MySQL, Firebase Realtime Database
- **Pagamentos**: Stripe, InfinitePay, PagBank (checkout + webhooks)
- **Infra**: Docker, Netlify, AWS S3
